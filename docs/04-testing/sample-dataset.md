# 해빙 — 예시 자료 세트

이 자료는 **해빙을 직접 써 보기 위한 합성 이미지**입니다. 실제 인물·계좌·거래가 아니며
개인정보가 들어 있지 않습니다. 서비스에 그대로 올려서 전 과정을 확인하실 수 있습니다.

페르소나별로 **한 폴더 = 한 사건**입니다. 폴더 안의 장들은 등장인물·금액·날짜·계좌가
서로 맞물려 있어서, "구매자–송금인 일치" 같은 점검이 실제로 동작하는지 보입니다.

**처음이시면 `P-01_중고거래_해피패스`부터 보세요.** 전 구간이 막힘 없이 통과하는
기본 시나리오입니다.

규격은 실제 업로드와 같습니다 — **738×1600 PNG**.

| 폴더 | 페르소나 | 기대 결과 | 무엇을 보는가 |
| --- | --- | --- | --- |
| `P-01_중고거래_해피패스` | 김도현 (28) | **제출 준비 완료** | 데모 메인. 전 구간이 막힘 없이 통과하는지 |
| `P-02_용역대가_증빙보완` | 박은지 (31) | **증빙 보완 필요** | 재직 증빙 계열이 "이 중 하나만"으로 묶여 보이는지 |
| `P-03_사업매출_협박` | 이상우 (45) | **제출 준비 완료** + 협박 배너 | 협박 감지가 화면 배너까지 이어지는지 |
| `P-04_이름불일치_은행확인` | 최민혁 (36) | **은행 확인 필요** | 이름 불일치를 "의심"으로 다루지 **않는지** |
| `P-05_채권회수_저신뢰` | 장수연 (52) | 확인 질문 후 분기 | 못 읽은 값을 지어내지 않고 막는지 |
| `공통_엣지케이스` | — | 케이스별 상이 | 방어 장치들 |

**P-06(윤태식, 68세)은 이미지가 없습니다.** 자료 0건으로 문진만 쓰는 페르소나라
업로드 화면에서 **[자료 없이 계속하기]** 를 누르면 그게 테스트입니다.

### ZIP 다시 만들기

이미지 원본은 이 저장소에 두지 않고 **ZIP 안에만** 둡니다(같은 2MB를 두 벌 두지 않기 위해서).
안내문만 고칠 때는 ZIP 안의 `00_읽어보세요.md`를 이 파일 내용으로 갈아끼우면 됩니다.

```python
import zipfile, shutil, unicodedata
# 이미지는 기존 ZIP에서 그대로 가져오고 안내문만 교체한다
src, dst = "haebing-sample-evidence.zip", "new.zip"
with zipfile.ZipFile(src) as a, zipfile.ZipFile(dst, "w", zipfile.ZIP_DEFLATED) as b:
    for item in a.infolist():
        if item.filename.endswith("00_읽어보세요.md"):
            continue
        b.writestr(item, a.read(item.filename))
    b.write("sample-dataset.md", "해빙-예시자료/00_읽어보세요.md")
```

**파일명은 NFC로 넣습니다.** macOS는 파일명을 NFD로 주는데, 그대로 압축하면 윈도우
탐색기에서 한글 자모가 분리돼 보입니다. `unicodedata.normalize("NFC", name)`을 거칩니다.
파이썬 `zipfile`은 비ASCII 이름에 UTF-8 플래그를 세우므로 윈도우에서 정상적으로 풀립니다.
