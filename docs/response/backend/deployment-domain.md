## 1. 등록해 주실 값

```
https://2026-finance-ai-challenge-tau.vercel.app
```

`api-contract.md`의 CORS 허용 origin 표에 추가해 주세요. **끝에 슬래시를 붙이지 않습니다** — origin 비교는 문자열 일치라 `https://…app/`은 매칭되지 않습니다.

| 항목 | 값 |
| --- | --- |
| 허용 origin | `http://localhost:5173` (기존) + **`https://2026-finance-ai-challenge-tau.vercel.app`** (신규) |
| 허용 헤더 | `Content-Type`, `X-Session-Hash` (변경 없음) |
| 허용 메서드 | `GET`, `POST`, `DELETE`, `OPTIONS` (변경 없음) |
| `credentials` | 사용하지 않음 (쿠키 미사용, 변경 없음) |

**프리뷰 와일드카드는 요청하지 않습니다.** 2026-08-24에 합의한 대로 프로덕션 도메인 1개만 쓰고, 프리뷰 확인은 로컬로 대체합니다. Vercel이 푸시마다 만드는 `*-git-*.vercel.app`은 API를 호출할 수 없는 상태로 두는 것이 맞습니다 — 임의 브랜치·포크 배포에서 API가 열리는 것을 막기 위한 결정이었습니다.

## 2. 배포 환경

| 항목 | 값 |
| --- | --- |
| 호스팅 | Vercel (Hobby) |
| 빌드 | 저장소 `frontend/`를 Root Directory로 지정, Vite 프리셋 |

PRD §8.1이 정적 호스팅을 권한 이유(스핀다운 개념 자체가 없음)를 그대로 따랐습니다. 백엔드 Render처럼 **접근 불가 구간이 생기지 않습니다.**

## 3. 확인한 것

배포 직후 실제로 열어 확인했습니다.

| 확인 | 결과 |
| --- | --- |
| HTTP 응답 | `200` · `server: Vercel` |
| 화면 렌더 | 정상 (첫 화면 · 통계 · 협박 배너) |
| 최신 커밋 반영 | **확인됨** — 배포된 번들 해시가 로컬 빌드와 동일(`index-DuX-nYhg.js`), 오늘 올린 카드 확인(F4-06)·서식 입력(S04-1)까지 포함 |

**SPA fallback 설정(`vercel.json` rewrites)은 넣지 않았습니다.** 라우터 없이 단계 상태로만 화면을 바꾸는 구조라 경로가 `/` 하나뿐입니다. 나중에 라우터를 도입하면 그때 추가합니다.

## 4. 심사 기간(9/7~9/11) 운영

대회 규칙상 이 URL이 **9/7 11:00 ~ 9/11 23:59 접근 가능**해야 하므로, 그 기간에는 **프론트가 main에 푸시하지 않겠습니다.** 자동 배포가 걸려 있어 푸시하면 심사 중에 화면이 바뀝니다.

로드맵의 "9/7~9/11 매일 아침 3개 URL 확인" 로테이션에는 그대로 참여합니다.

## 6. 참고 — 이 문서를 여기 둔 이유

`roadmap.md`의 프론트 과제 표에는 회신 위치가 **`../response/frontend/`** 로 적혀 있는데, 그건 **프론트가 읽는 폴더**입니다. 이 문서는 백엔드가 읽고 CORS에 등록해야 하는 내용이라 `response/backend/`에 뒀습니다 (`../README.md` "폴더 이름 = 이 문서를 읽을 사람").

로드맵 쪽 표기를 고쳐 주시면 다음 사람이 헷갈리지 않겠습니다. **문서 소유가 백엔드라 프론트가 손대지 않았습니다.**
