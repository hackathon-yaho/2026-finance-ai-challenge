- 원본 요청: `../../request/ai/demo-response-set.md` (2026-08-23)
- 회신: AI · 2026-08-25

## 결정 사항 수용 + **v1 파일 조기 납품**

- 응답 세트를 **백엔드 리소스(`src/main/resources/demo/`)에 탑재하고 `DEMO_MODE=true`면 AI-server를 호출하지 않는다**는 팀 결정에 동의합니다. 오프라인 발표에서 네트워크 경로 자체를 타지 않아야 한다는 이유가 맞습니다.
- 시점은 F11-03대로 9/1~9/2 완성도 단계에 확정하되, **v1을 지금 만들어 저장소에 넣었습니다** — Phase 3 `AiClient` 개발·단위 테스트 픽스처로도 바로 쓸 수 있고, 마지막에 몰아서 만드는 리스크를 없애기 위해서입니다.

## 스키마에 대한 주의 2가지

1. **이번 회신 3건의 스키마 확장이 선반영되어 있습니다** — 카드에 `source_type`, `counterparty_name`, `payer_name`이 들어 있고, `checklist`는 빈 배열, `quality_flags.amount_mismatch`는 항상 `false`입니다(백엔드 미사용 값 정책 그대로). 백엔드가 계약 문서에 스키마를 반영한 뒤 어긋나는 부분이 생기면 제가 파일을 다시 맞추겠습니다 — **계약 문서가 항상 우선**입니다.
2. **`imageIndex`·`bbox`는 실제 데모 캡처와 아직 동기화되지 않은 그럴듯한 값입니다.** 발표 리허설(9/1~9/2)에서 실제 사용할 데모 이미지 4장이 확정되면, 그 이미지를 제 추출 파이프라인에 실제로 통과시킨 결과로 **v2를 재생성**해 교체하겠습니다. 문장 클릭 → 원본 이동 시연이 자연스러우려면 이 동기화가 필수입니다.

## 백엔드가 해야 할 후속 작업

1. v1 파일을 `src/main/resources/demo/`로 복사, `DEMO_MODE=true` 분기에서 TC별 매핑 방식 결정 (파일명 그대로 써도 되고, 세션 문진 응답과 무관하게 고정 세트를 돌려도 됩니다 — F11-03의 "혼합 금지·배지 표시"만 지켜지면 됩니다).
2. 데모 리허설 일정(9/1~9/2)에 실제 데모 이미지 4장 확정을 안건으로 — 확정 즉시 v2를 만들어 드립니다.
