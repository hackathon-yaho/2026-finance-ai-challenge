## 1. 필드가 실제로 도착합니다

같은 이미지(`04_자동이체_통신비.png`)를 다시 넣어봤습니다.

```
POST :8080/api/evidence  →  200, 7.3초
  occurred_at: 2025-09-15T00:00:00+09:00 | amount: 65890
  recurrence : {"count": 12, "period": "monthly",
                "first": "2025-09-15T00:00:00+09:00", "last": "2026-08-15T00:00:00+09:00"}
```

어제 같은 호출에서 키가 통째로 없던 자리입니다. `DemoFixtures.remapIds`까지 같이 보신 것 감사합니다 — 저희는 그 경로를 못 봤습니다.

## 2. 미리보기 3면 — 열이 하나 모자랐습니다

**여기가 저희 쪽 문제였습니다.** 서버 PDF 3면은 `일시 | 행위 주체 | 요약 · 금액` 세 열인데, 미리보기는 **일시·요약 두 개만** 그리고 있었습니다. 금액이 아예 안 보였고, 그래서 "(1회분)"이 들어갈 자리조차 없었습니다. `recurrence`를 붙이려다 발견했습니다.

주체와 금액을 넣고, 요약과 금액을 잇는 ` · `까지 같은 자리에 뒀습니다.

```
2025.09.15 00:00  시스템  SK텔레콤 통신요금이 자동 출금됨 (매월 12회) · 65,890원 (1회분)
```

## 3. 미리보기 4면 — 단일 카드 + 반복

`dateRangeLabel`·`summaryLabel`의 조건을 그대로 옮겼습니다. **카드가 하나뿐일 때만** 전체 기간과 `(매월 12회, 1회분 …)`을 쓰고, 여러 장 그룹은 종전처럼 `occurred_at` 범위 + "N건 확인됨"입니다.

```
1  본인 서술  2025.09.15 00:00 ~ 2026.08.15 00:00  SK텔레콤 통신요금이 자동 출금됨 (매월 12회, 1회분 65,890원)
```

두 분기 다 브라우저에서 확인했습니다 — 카드 2장(반복 아님) 그룹은 `2건 확인됨`으로, 1장 반복 카드는 위처럼 나옵니다.

**한 가지 다른 점**: 저희 미리보기는 날짜를 `2025.09.15`(점)로 씁니다. PDF는 `2025-09-15`(하이픈)입니다. 화면 전체가 점 표기라 맞춰 뒀는데, **내용은 같고 구분자만 다릅니다.** 통일이 필요하다고 보시면 저희가 하이픈으로 바꾸겠습니다.

## 4. 카드 화면은 어제 먼저 붙여뒀습니다

`58c9336` — 칩 줄에 "매월 · 12회" 배지, 금액 라벨 "금액 (1회분)", 아래 한 줄에 기간. PDF에 대응하는 면이 없어 문구를 맞출 필요가 없는 자리라 먼저 했습니다.
