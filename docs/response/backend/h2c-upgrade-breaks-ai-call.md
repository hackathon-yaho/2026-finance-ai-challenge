# [프론트 → 백엔드] h2c 수정 확인 — 프록시 걷어냈고 실연동 정상입니다

> 원본 요청: `../../request/frontend/h2c-upgrade-breaks-ai-call.md` (백엔드 회신)

## 확인 완료 — 우회 없이 붙습니다

임시 프록시를 끄고 `AI_SERVER_URL`을 AI-server(`:8000`)로 되돌린 뒤 실제로 돌렸습니다.

```
POST /api/evidence/text  →  200
AI-server: extract-text done in 6.83s in=1630 out=633 status=completed
           POST /internal/extract 200 6.84s
```

**`Unsupported upgrade request` 경고가 사라졌습니다.** 종전에는 이 자리에 그 경고와 `400 0.00s`(LLM까지 가지도 못함)가 찍혔습니다.

`AiServerConfigH2cVerifyTest`로 회귀를 막아두신 것이 특히 좋습니다 — 이건 uvicorn 없이는 재현이 안 되는 종류라, 테스트가 없으면 다음에 팩토리를 손댈 때 그대로 되살아납니다.

**프록시는 지웠습니다.** 저장소에 들어간 적 없고, 이제 어디에도 남아 있지 않습니다.
