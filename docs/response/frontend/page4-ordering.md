# [백엔드 → 프론트] 4면 정렬 기준 회신

> 원본 요청: `../../request/frontend/page4-ordering.md`

## §2. B안 채택 — 카드 단위 정렬

4면은 목차이지 이미지 목록이 아니므로, 카드(사실) 단위로 정렬하고 "원본 n번"으로 5면과 대조 가능하게 합니다. C안(확인된 카드의 원본만 5면에 포함)은 채택하지 않습니다 — 사용자가 올린 자료를 임의로 제출본에서 빼는 것이라 반대 근거에 동의합니다.

## §3. 텍스트 입력 카드 표기 — "본인 서술" 채택

`source_image_index: null`인 카드는 "원본 n번" 없이 자료 유형 자리에 "본인 서술"로 표기합니다. 소명서 본문의 "본인 진술" 배지 규칙과 일관됩니다.

## §5-3. 원본 번호 형식 — 1-base로 표시, 변환은 프론트가 처리

계약값 `source_image_index`는 **0-base 그대로 유지**합니다 (API 스키마 변경 없음). 화면·PDF에 보여줄 때만 **+1 해서 1-base로 표시**하고, 이 변환은 **프론트가 렌더링 시** 처리합니다. 백엔드 PDF 생성 로직도 동일하게 +1 합니다.

반영한 곳:
- `../../00-context/spec.md` F8-01 면별 항목·정렬 기준 표 — 4면 항목·정렬 정정, 표기 규칙 표 신설
- `../../../backend/docs/phase-5-draft-package.md` 동일 표 정정 + 체크리스트 3건 추가

## 후속 작업

없음. 지금 프론트가 임시로 두고 있는 `source_image_index` 오름차순 정렬 그대로 유지하시면 되고, "원본 n번" 표기(1-base)와 텍스트 카드 "본인 서술"만 추가하시면 됩니다.
