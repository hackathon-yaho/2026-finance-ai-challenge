## 배경

`test-cases-and-demo.md`는 데모 모드 담당을 "AI(사전 녹화 응답 세트 준비) + 백엔드(모드 전환 스위치)"로 나눴는데, **그 응답 세트가 어느 서비스에 물리적으로 놓이는지**가 문서에 없었습니다.

팀 결정(2026-08-23): **백엔드 리소스(`src/main/resources/demo/`)에 탑재하고, `DEMO_MODE=true`일 때 백엔드가 AI-server를 호출하지 않습니다.**

이유는 데모 모드의 목적 자체입니다 — 발표는 오프라인이고 현장 네트워크가 끊기면 백엔드→AI-server 경로도 같이 끊깁니다. AI-server가 응답 세트를 들고 있으면 정작 필요한 순간에 못 씁니다.

## 요청 산출물

JSON 파일로 주세요. 스키마는 `internal-api-contract.md`의 실제 응답과 **완전히 동일**해야 합니다(백엔드가 변환 없이 그대로 반환합니다).

### 1. 판독 결과 6종 — `/internal/extract` 응답 형식

`test-cases-and-demo.md`의 TC-01~06을 완주할 수 있는 구성으로 부탁드립니다.

| # | 내용 | 대응 TC |
| --- | --- | --- |
| 1 | 중고판매 — 대화·입금·배송 전부 (`delivery_evidence: true`) | TC-01 |
| 2 | 용역 — 입금내역만 (배송·용역 증빙 없음) | TC-02 |
| 3 | 자료 충분 + **협박문자** (`threat_detected: true`) | TC-03 |
| 4 | TC-01과 동일 자료 (문진의 과거 이력만 바꿔 상태가 뒤집히는 시연용) | TC-04 |
| 5 | 금액 신뢰도 `low` 카드 포함 | TC-05 |
| 6 | 이벤트 0건 (자료 없음 경로) | TC-06 |

### 2. 소명서 응답 1종 이상 — `/internal/draft` 응답 형식

`draftText` / `sentences[].evidenceRefs` / `checklist` / `factCheckPassed` 포함. 발표 시연에서 **문장 클릭 → 근거 원본 이동**(TC-12, 데모 `[2:20]`)을 보여줘야 하므로 `evidenceRefs`의 `imageIndex`·`bbox`가 실제 값으로 채워져 있어야 합니다.

## 백엔드가 함께 처리하는 것

- 응답에 데모 모드 플래그를 담아 프론트가 "예시 데이터 사용 중 — 실제 AI 분석 결과가 아닙니다" 배지를 고정 표시하게 합니다.
- 실제 업로드 파일과 데모 데이터를 화면 표시 없이 섞지 않습니다 (F11-03 금지 조항).
