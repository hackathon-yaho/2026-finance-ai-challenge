## 1. 요청 — 카드에 두 종류의 "이름"을 담아주세요

`/internal/extract` 응답의 카드에 **대화 상대명**과 **입금자명**을 구분해서 담아주세요.

```json
{
  "event_id": "evt_003",
  "actor": "counterparty",
  "counterparty_name": "김OO",        // ← 신규: 대화 상대 표시명/닉네임
  "payer_name": null,                  // ← 신규: 입금 내역상 입금자명
  ...
}
```

- 대화 캡처에서 나온 카드 → `counterparty_name` (플랫폼 닉네임, 저장된 이름 등 화면에 보이는 표시명)
- 입금 내역 캡처에서 나온 카드 → `payer_name` (거래내역의 입금자 표기)
- 해당 없으면 `null`. **추측해서 채우지 마세요** — 없으면 없는 대로 두는 편이 낫습니다.
- 신뢰도가 필요하면 `field_confidence`에 함께 넣어주세요.

필드명은 제안이며, 다른 이름을 쓰셔도 계약에 적히면 그대로 맞추겠습니다.

## 2. 왜 필요한가

금융감독원이 2026년 5월 이의제기 업무처리를 표준화하면서, **물품 거래 공통 소명자료에 "구매자와 송금인이 일치하는지 확인할 수 있는 자료"** 를 넣었습니다. KB국민은행 공식 고객 안내에도 같은 문구가 있습니다.

**통장협박·삼각사기의 판별 지점이 정확히 여기입니다.** 사기범이 피해자를 시켜 판매자 계좌로 송금하게 만들기 때문에 **대화 상대와 입금자 이름이 다릅니다.** 은행이 가장 먼저 보는 항목입니다.

실제 사례(서울경제 보도): 순금 팔찌를 판 A씨의 경우, 구매자 B가 **전혀 모르는 제3자 C의 계좌에서** 송금하게 만든 구조였습니다.

지금 카드 스키마에는 `actor`(`self`/`counterparty`/`system`) 3값만 있어 **이름을 담을 자리가 없습니다.** 백엔드가 대조 로직을 만들 수 없습니다.

## 3. ⚠️ 개인정보 규칙과의 관계 — 확인이 필요합니다

`privacy-and-safety.md`가 추출 프롬프트에 **"전화번호·계좌번호 전체·주민번호를 추출하지 않도록 강제"** 를 걸어놨고, `spec.md` F4-03 마스킹 대상에 **"실명"** 이 들어 있습니다.

이번 요청은 그 규칙과 **부딪힙니다.** 아래를 전제로 요청합니다.

- **대조에 필요한 최소 형태로만** 뽑아주세요. 전체 실명이 필요하지 않다면 **부분 마스킹된 형태**(예: `김O수`, `홍*동`)로도 대조가 가능한지 AI 담당 의견을 주세요.
- 백엔드는 이 값을 **일치/불일치 판정에만 사용**하고 세션에는 판정 결과만 남기는 방안을 검토 중입니다.
- 다만 **소명서 본문에 상대방을 특정해 서술해야 할 수도** 있어(사실 기재), 어느 수준까지 필요한지는 AI·백엔드가 함께 정해야 합니다.

**회신에서 이 부분에 대한 판단을 꼭 주세요.** 개인정보 방어 논리를 건드리는 사안이라 백엔드 단독으로 결정하지 않겠습니다.

## 4. 판정 자체는 백엔드가 합니다

**AI는 이름을 추출만 하고, 일치/불일치 판정은 하지 마세요.**

- 이름 표기는 원래 다를 수 있습니다 — 닉네임 vs 실명, 법인명 vs 대표자명, 띄어쓰기·가운뎃점
- **불일치가 곧 문제가 아닙니다.** 삼각사기 피해자는 원래 불일치합니다. 이건 "설명이 필요한 항목"이지 "위험 신호"가 아닙니다
- 준비도 판정은 결정적 규칙 엔진의 몫입니다 (`reason-type-rules.md` §0)

AI가 `payer_matches: true/false` 같은 판정 필드를 만들지 않도록 부탁드립니다.

## 5. 회신이 필요한 항목

| # | 항목 |
| --- | --- |
| 1 | 필드명·구조 확정 (제안대로 / 다른 이름) |
| 2 | **부분 마스킹 형태로 대조가 가능한지** — 개인정보 규칙과의 절충안 |
| 3 | 대화 캡처에서 상대 표시명 추출의 실제 정확도 (플랫폼별로 화면이 달라 어려울 수 있음) |
| 4 | 입금 내역 캡처에서 입금자명 추출의 실제 정확도 |

3·4번이 낮게 나오면 이 기능 자체를 접는 것도 선택지입니다. **가능성을 부풀리지 말고 실제 판독 난이도를 알려주세요.**
