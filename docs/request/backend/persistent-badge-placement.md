## 1. 무엇을 바꿨나

| | 종전 (명세대로) | 지금 |
| --- | --- | --- |
| 배지 노출 | **전 화면 상단 고정** | **진입 화면(S00)에만** |
| 판정 화면의 고지 | 배지 + 각 화면의 자체 문구 | 각 화면의 자체 문구 |

**빼기 전에 화면별로 대체 문구가 있는지 먼저 확인했습니다.**

| 화면 | 문구 | 출처 |
| --- | --- | --- |
| S00 진입 | "이 화면은 제출 자료를 정리하는 도구예요…" | 상단 배지 |
| S01 문진 | 없음 | — 아직 아무 판정도 나오지 않은 단계 |
| S02 증거 | 없음 | — 같음 |
| **S03 준비도** | **"최종 판단은 은행이 합니다"** | 도장 바로 아래 · `reason-type-rules.md` §3 필수 |
| **S04 소명서** | **"AI 초안 · … · 최종 판단은 금융회사"** | 문서 상단 캡션 · `spec.md` F8-01 표기 |
| **S05 접수** | "이 화면은 제출 자료를 정리하는 도구예요…" | 본문 끝 (복구함) |

**오해가 생길 수 있는 자리는 전부 덮여 있습니다.** 배지가 막으려는 것은 *"준비도 결과를 승인 예측으로 오해"*(PRD §11)인데, 판정이 나오는 세 화면(S03·S04·S05)이 각자 더 구체적인 문장을 이미 갖고 있습니다. S01·S02는 아직 아무 판정도 없어 오해할 대상 자체가 없습니다.

## 2. 왜 바꿨나

6단계 내내 같은 문장이 상단에 따라붙으면 **오히려 읽히지 않습니다.** 세 번째 화면쯤부터는 배경으로 인식됩니다. 정작 중요한 순간(준비도 도장이 찍히는 순간)에 눈에 들어와야 하는데, 그때는 이미 시선에서 지워진 상태가 됩니다.

프론트 담당 판단이며, **고지의 실질은 §1 표대로 유지**된다고 봅니다.

## 3. 확인 부탁드립니다

| 안 | 내용 |
| --- | --- |
| **A (권장)** | 두 문서의 표기를 **"진입 화면 + 판정이 나오는 화면"** 으로 정정. §1 표를 근거로 삼으시면 됩니다 |
| B | 전 화면 고정을 유지해야 한다고 보시면 알려주세요 — **되돌리는 데 한 줄이면 됩니다** |

**규제 대응 문구라 문서와 구현이 어긋난 채로 두는 것이 제일 나쁩니다.** 심사에서 문서 대조로 확인될 수 있는 항목이라 어느 쪽이든 맞춰두는 편이 낫습니다.
