## 요청

`deploy-handoff.md` §1 회신에서 **"백엔드가 생성했고 팀 채널로 따로 전달하겠다"** 고 하셨는데, **아직 값을 받지 못했습니다.** 전달 부탁드립니다.

## 값 자체는 이 문서에 적지 마세요

기존 합의(`../../response/backend/image-transfer-and-internal-auth.md`)대로 **값은 문서·저장소에 남기지 않습니다.** 이 문서는 "요청과 처리 상태"만 기록하는 자리입니다.

전달은 아래 중 아무 편한 방법이면 됩니다.

| 방법 | 비고 |
| --- | --- |
| 팀 채널 DM | 기존 합의 방식 |
| 그 밖의 비공개 경로 | 저장소·공개 이슈만 아니면 됩니다 |

받으면 제 쪽에서 **Google Secret Manager**에 등록합니다. 코드에도 저장소에도 값이 들어가지 않습니다.

## 왜 제가 만들면 안 되는가 (확인차 적습니다)

이 값은 **양쪽이 정확히 같은 문자열**을 가져야 인증이 성립합니다. 백엔드가 이미 생성해 `backend/.env`에 넣어 두셨으므로, 제가 새로 만들면 두 값이 달라져 **모든 `/internal/*` 호출이 401로 막힙니다.** 그래서 새로 만들지 않고 기다리고 있습니다.

> 혹시 아직 실제로 생성하지 않으셨다면, **제가 만들어 전달하는 것도 괜찮습니다.** 회신에 "AI가 생성해 달라"고만 적어 주세요. 어느 쪽이든 **한쪽이 만들어 다른 쪽에 주는 것**이 중요하고, 누가 만드는지는 상관없습니다.

## 참고 — 받은 뒤 제가 할 것

1. Secret Manager에 등록 → Cloud Run 재배포
2. 배포 URL로 계약 확인 3종 실행 (`../../../ai-server/docs/deployment.md`)
   - `/internal/health` 무인증 200
   - 토큰 없는 요청 401
   - 10MB 이미지 통과
3. `AI_SERVER_URL`을 팀 채널로 전달
