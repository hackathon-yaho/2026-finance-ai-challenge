## 1. 총괄표의 F3-04 담당이 `B`인데 화면은 프론트가 만듭니다

`spec.md` 총괄표는 이렇게 되어 있습니다.

| ID | 기능명 | 우선 | 담당 | 화면 |
| --- | --- | --- | --- | --- |
| F3-04 | 텍스트 직접 입력 대체 | P1 | **B** | S02-1 |

**추출은 AI가 맞습니다.** 자연어를 이벤트로 분해하는 건 AI-server 몫이고 이미 구현돼 있습니다(`ai-server/app/services/extraction.py`의 텍스트 경로).

**그런데 화면 정의서에 S02-1이 등재돼 있습니다.** 화면은 프론트가 만듭니다. 지금 표기로는 이 화면을 누가 만드는지 알 수 없습니다.

**F8-01 때와 같은 형태의 어긋남으로 보입니다** — 총괄표 한 칸만 다른 문서들과 맞지 않는 경우요. 그때처럼 **`B/C`(추출=B, 화면=C)** 로 정정해 주시면 좋겠습니다. F7-05가 이미 `B/C`, F7-06이 `A/C`로 되어 있으니 같은 표기법입니다.

**프론트가 이미 만들었으므로 일정에 영향은 없습니다.** 문서만 실제와 맞추면 됩니다.

## 2. ⚠️ 개인정보 마스킹을 **전송 전**에 하기로 했습니다 — 확인 부탁드립니다

`prd.md` FR-027은 이렇게만 적혀 있어 **주체가 명시돼 있지 않습니다.**

> 텍스트 직접 입력(FR-026) 경로는 정규식으로 자동 마스킹

현재 AI-server는 **추출 후처리**에서 가립니다(`ai-server/app/pii.py`가 `summary`를 스크럽). 즉 **LLM은 원문을 그대로 봅니다.**

프론트는 **보내기 전에** 가리도록 만들었습니다.

| | 종전 해석 | 프론트 구현 |
| --- | --- | --- |
| 마스킹 시점 | 추출 후 (AI-server) | **전송 전 (브라우저)** |
| LLM이 보는 것 | 원문 | 이미 가려진 텍스트 |

**이유**: 이미지 경로가 **사용자가 가린 뒤 전송**하는 구조인데(F3-06), 텍스트만 원문을 보내면 같은 서비스 안에서 원칙이 갈립니다. §5.1 처리 흐름도 "마스킹 → 전송" 순서입니다. 지우고 보내면 LLM이 애초에 보지 않습니다.

**패턴은 좁게 잡았습니다** — 주민등록번호 / 휴대전화번호 / 계좌번호 형태만입니다. 넓게 잡으면 금액이나 계좌 뒷자리처럼 소명에 필요한 값까지 지워집니다. 무엇을 가렸는지는 보내기 전에 화면에서 알려줍니다("주민등록번호 · 전화번호는 가리고 보낼게요").

**확인이 필요한 것**

1. 이 시점 변경에 동의하시는지 — 동의하시면 `prd.md` FR-027 또는 `api-contract.md`의 `/api/evidence/text` 절에 **마스킹 주체를 명시**해 주세요. 지금은 어느 쪽으로도 읽힙니다
2. **AI 담당에게 공유가 필요합니다** — AI-server가 받는 `rawText`가 이미 가려진 상태가 됩니다. `pii.py`의 후처리는 그대로 두는 편이 안전합니다(이중 방어). 다만 평가 세트에서 "개인정보 미추출"을 잴 때 입력 조건이 달라질 수 있습니다

## 3. 프론트가 지킨 F3-04 규칙

회신에 필요한 내용은 아니고, 구현이 명세대로인지 확인하실 수 있도록 적어둡니다.

| 명세 | 구현 |
| --- | --- |
| 최대 2000자 + 예시 문구 | 글자 수 표시와 함께 제공 |
| 진입 ① `[글로 직접 쓰기]` | 업로드 화면 하단에 배치 |
| 진입 ② 전체 판독 실패 시 자동 전환 | 화면·문구는 준비됨. **API 연동 후 실제 동작** (지금은 목이라 실패가 없음) |
| `occurred_at` 신뢰도 전부 `low` | 승격하지 않음. 따라서 날짜가 있는 카드는 **확인 게이팅에 걸림** |
| **말하지 않은 시각을 만들지 않음** | 날짜만 있는 값은 시·분을 만들지 않고 날짜만 표기. 타임라인도 "시각 미상"으로 둠 |

> 마지막 항목에서 실제로 버그를 하나 잡았습니다. `2026-09-01`을 `new Date()`로 파싱하면 UTC 자정이 KST **09:00**으로 찍혀, 사용자가 말하지 않은 시각이 화면에 나타나고 있었습니다. 날짜만 있는 값은 날짜만 그리도록 고쳤습니다.
